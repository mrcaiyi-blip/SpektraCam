# 验证记录

## 2026-11-09

- **独立构建**　从新项目源码的干净副本构建 Android 调试 APK 和 iOS Release。Android Lint 无错误。
- **显影**　原工程和新工程的胶片集成、八种测光及并行测光测试通过。新工程的 MoltenVK 测试覆盖跨 128 行条带、线性高光余量、截断输入，以及从单张 Bayer RAW 到 Portra 400 负片和 Provia 100F 正片的完整处理。
- **原引擎对照**　同一台 Mac 上，给原工程与新工程输入同一个带行填充的 141×263 RAW 合成图。四种 Bayer 排列均启用独立黑电平、白平衡、CCM 和高光保色。启用镜头阴影校正与 DNG Stage 3 暗角校正的组合也纳入测试。每种排列的 111,249 个线性 RGB 样本均逐样本相等。
- **资源与依赖**　验证全部 20 个 65³ 预览 LUT 的哈希、格式和胶片／相纸配对。两端安装产物的胶片资源与源码一致。Android APK 的唯一原生库是胶片 JNI，ELF 和 APK 均通过 16 KB 对齐检查。
- **iPhone 16 Pro Max**　开发签名安装并启动，用户完成实拍。镜头更新后，AVFoundation 报告后置 0.5×、1×、5× 与前置支持 Bayer RAW。日志记录了 0.5×、5×、1× 的实际切换。
- **Android 显影测试 APK**　已编译合成 Bayer RAW 的设备测试。它读取安装包内的胶片资源，经 Vulkan、JNI 和 Android Bitmap 验证负片和正片输出。ADB 当前未发现设备，设备测试待运行。
- **待验证**　Android 真机拍摄到相册和不同设备的物理镜头组合。iOS 各镜头的成片画质、存储和长时间连续拍摄仍需逐项验收。

## 真机验收步骤

1. 打开应用并允许相机访问。确认默认曝光为「直方图中灰」，切换 Portra 400 和 Provia 100F 后确认取景色彩随所选胶片变化。
2. 用每个可用的物理 RAW 镜头拍一张，并分别验证首次拍摄和连续拍摄。iPhone 16 Pro Max 检查 0.5×、1×、5× 和前置。2× 单独验证广角裁切。
3. 在系统相册打开新照片，核对拍摄顺序、方向和裁切，并查看亮部与暗部细节。记录设备型号、系统版本、胶片、镜头和保存结果。
